## Transcribe 1.8.0

The biggest release yet: turn any audio file into a Word document, send meeting notes straight to Notion, and summarize meetings of any length with local models.

### ✨ Transcribe Files — audio in, Word document out

A new **Transcribe Files** tab (you can't miss it). Drop in any audio or video file — MP3, WAV, M4A, FLAC, even MP4/MKV — and get a polished **.docx** transcript with **speaker labels** (Speaker 1/2/3), **timestamps**, and readable paragraphs.

- Runs **entirely on your computer** — nothing is uploaded, ever.
- **Auto model choice**: picks the best speech model your machine can actually run (your GPU if it works, a fast model on CPU), or choose one yourself.
- A real **progress bar** with stages and a live *time-left* estimate, and Cancel works mid-job.
- **Free covers files up to 1 hour · Pro extends that to 5 hours.**

### 📝 Send meeting notes to Notion

A **Send to Notion** button on the meeting results page publishes the title, formatted notes (with checkbox action items) and the speaker-labeled transcript to a Notion page of your choice. One-time setup with your own Notion integration — the app walks you through it, including the "share the page with the integration" step everyone misses.

### 🐛 Fixes & improvements

- **Long meetings no longer fail on local AI models.** "Requested tokens exceed context window" is gone: the context window is 4× larger, and anything beyond it is summarized in stages automatically — any meeting length now works.
- **Retry Summary can now switch engines.** When notes fail (or fall back), pick a different AI — each option tagged **PRO / LOCAL / CLOUD** — and retry without re-recording. Cloud engines ask for their API key right there.
- **No more silent downgrades**: if your chosen notes engine isn't set up, the notes say so and Retry stays available — instead of quietly giving you the basic formatter.
- **Meeting results look like a document now** — formatted notes with real headings and checkboxes, and a transcript with bold speaker labels instead of a wall of text.
- Word documents survive any transcription content — stray control characters from noisy audio can no longer produce a file Word refuses to open.
- File transcription, dictation and meetings politely take turns on the speech model instead of stalling each other.
- Crisper icons everywhere: the mic/speaker glyphs and PRO/LOCAL/CLOUD tags now render at native resolution on every display.

### Notes

- Speaker identification remains **beta**; accuracy depends on clear, distinct voices.
- Long files on CPU-only machines take a while — the time-left estimate is honest, and Pro's cloud engines are the fast path for the summary side.
