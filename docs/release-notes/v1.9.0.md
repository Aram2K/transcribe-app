## Transcribe 1.9.0

**Live Prompter** — a private, real-time AI copilot for your calls — plus a full meeting library and a much faster AI path.

### ✨ Live Prompter (new)

A floating liquid-glass card that sits over Zoom, Teams, Meet or any call and helps you *while you talk*:

- **Start** on the card begins live transcription of the call (system audio + your microphone). A green timer runs; the red button stops and generates the meeting notes.
- **NOW** shows the last thing said; **SO FAR** is a running AI summary that updates every ~20 seconds.
- **Say next / Follow-ups / Recap**, or type any question — answers **stream in instantly** (first words in a fraction of a second) with bold key phrases, bullets and code blocks when relevant.
- **Screen context (Auto)**: when you or the other side refer to what's on screen ("as you can see on this slide", "what does this error mean?"), a screenshot goes to the AI automatically. The card itself is never in it.
- **Private by default** — the card is **excluded from screen sharing and recordings** (Windows 10 2004+). What you see stays yours; the eye badge always tells the truth about the current state.
- Open it with **Ctrl+Alt+A** (change it in Settings → General, press-to-set), from the tray, or from the meeting window. Light / dark glass, collapse to a pill, drag anywhere.

Live Prompter is a privacy feature for your own notes during calls. Recording-consent guidance still applies, and it is not intended for interviews, exams or assessments where assistance is prohibited.

### 🗂 Meeting library

Settings → **History** now lists your meetings first. Open one for **Summary** and **Transcript** tabs, **Resume session** (continues the same meeting — the new part is appended and the notes regenerated), **Save recording** as **MP3 or WAV**, **Save as Word**, and Copy. Every recording segment is now saved with the meeting.

### ⚡ Faster, better AI

- **Streaming everywhere**: suggestions and answers appear token by token from local models and every cloud engine.
- **Cerebras** added as an engine (Settings → AI Actions → *Cerebras API – fastest, vision*): sub-second answers and screen-aware questions with one key.
- The live summary and suggestions are written by real AI models only — if no engine is connected, the app says so instead of showing a keyword extract.
- English by default for Live Prompter transcription and answers (configurable).

### 🎨 Interface

- Real liquid glass: the card refracts what's behind it, with a smooth edge, specular light and soft shadow — and stays clean over video.
- Redesigned header controls (Start · timer · stop · Private toggle · screen context) and the **Transcribe Files** tab highlighted with a gradient.
- Crisp, native-resolution icons and pills throughout.

### Notes

- Screen context needs a cloud AI engine (Transcribe Pro or your own key); local models answer from the transcript only and say so.
- macOS: the card is not excluded from screen capture (Apple provides no public API for it since 15.4); the badge shows this.
