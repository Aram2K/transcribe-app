## Transcribe 1.6.13

Small, sharp fixes on top of 1.6.12.

### 🎙️ Dictation

- **Esc now stops a transcription in progress**, not just an active recording.
  Press Esc anytime during "Transcribing…" or "Thinking…" to abort and discard
  the result - nothing gets pasted.

### ☁️ Cloud transcription

- **Fixed Fast cloud transcription failing (502) for Pro users.** The managed
  service now uses whichever server key is configured, so it works whether the
  Google or the Mistral key is set (it previously hard-required the Google key
  even when only Mistral was available). *Server-side fix - already live for
  everyone.*

### 🔒 Privacy Mode

- The cloud feature's **PRO badge now dims** (lower opacity) when Privacy Mode
  deactivates it, instead of disappearing - clearer that the feature is just
  turned off, not gone.
