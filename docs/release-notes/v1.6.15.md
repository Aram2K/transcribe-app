## Transcribe 1.6.15

### 🐛 Fixes the GPU "stuck on Finalising…" hang

If you have an NVIDIA GPU, local dictation could hang on "Finalising…" and
never produce text (while the same build worked fine on machines without a
GPU). Cause: the app transcribes audio in parallel chunks, but a Whisper model
isn't safe to run from several threads at once - on CUDA that deadlocks. All
local transcription is now serialized through a single inference lock, so the
GPU path is reliable. (CPU machines benefit too - no more cores fighting each
other.)

### ⛔ Esc truly stops everything

Pressing Esc now fully stops the current dictation - whether it's still
recording or already transcribing - and frees the app immediately, so the very
next hotkey starts a fresh recording. No more "finishing your previous
dictation, wait." A slow or stuck transcription is cancelled almost instantly.
