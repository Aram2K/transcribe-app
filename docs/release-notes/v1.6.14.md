## Transcribe 1.6.14

Reliability fixes for local and cloud transcription.

### Transcription

- **Fixed broken local Whisper cache recovery.** If the HuggingFace cache has
  broken snapshot links or an unreadable `model.bin`, Transcribe now attempts to
  repair the cache before giving up.
- **Cloud transcription falls back cleanly.** Google, Mistral, and managed cloud
  failures now fall back to local transcription when the local model is
  available, instead of stopping dictation with a provider error.
- **Clearer fallback errors.** If cloud fails and local fallback is also
  unavailable, the error explains both problems instead of showing a raw
  `model.bin` path.

### Overlay

- **Cloud status labels now name the model.** The transcribing overlay says
  `via gemini-2.5-flash AI`, `via voxtral-mini-latest AI`, or the selected
  model, instead of incorrectly saying `via Local AI`.
- **Esc cancellation is quieter.** After Esc cancels a transcription or Smart
  Action, Transcribe no longer shows the stale "previous dictation" popup while
  the worker finishes unwinding.
