## Transcribe 1.6.11 — Pro state you can trust

Two targeted fixes for problems reported on 1.6.1.

### 🔓 Pro features no longer lock themselves

- **Saving Settings could silently re-lock Pro features.** The Settings
  window kept a snapshot of the whole config and wrote it back on Save,
  which could revert the admin force-tier preview to an older value while
  the header still showed PRO — so a Pro user clicking *Meeting recording*
  suddenly hit the upgrade paywall. Live values like the tier preview are
  now excluded from the Save snapshot and can never be clobbered.

### 🪟 The window bottom stays on screen

- **Tall windows no longer hang off the bottom edge.** The window-fitting
  math counted only the inner (client) area, ignoring the OS title bar —
  so a window stretched near the screen height kept its bottom ~20–30 px
  below the visible desktop (typical on 1080p laptops at 125 % scaling).
  Fitting is now frame-aware: cap, centering, and nudge-back-into-view all
  account for the real window frame.
