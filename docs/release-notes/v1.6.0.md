## Transcribe 1.6.0 — Accounts, Pro, and the managed cloud

This is the biggest release yet: Transcribe grows from a local dictation tool
into a full product with accounts, a Pro plan, and zero-setup cloud features —
while keeping its core promise: **local dictation stays free, unlimited, and
private.**

### ✨ New

- **Accounts** — sign up with email or Google. Your free Smart Action trials
  and API keys now follow *your account*, not the computer.
- **Transcribe Pro** (€7.99/mo or €59/yr, 3-day free trial):
  - **Fast cloud transcription** — accurate transcription on our servers with
    no API key and no setup.
  - **Unlimited Smart Actions** — translate, rewrite, summarize, draft emails
    and meeting notes by voice, powered by a managed cloud model. No key needed.
  - **Meeting recording with AI notes** — record system sound + microphone and
    get clean minutes with decisions and action items.
- **Three meeting capture modes** — System sound + Mic, Microphone only, or
  System sound only (e.g. transcribe a webinar without picking up the room).
- **GPU acceleration** — local Whisper now uses your NVIDIA GPU when available
  and falls back to CPU automatically, even mid-dictation.
- **Free trial of Smart Actions** — every account gets 5 free Smart Actions to
  try before deciding on Pro.
- **In-app feedback** — paste screenshots straight into the feedback box
  (Ctrl+V), and it lands directly with the developer.

### 🔒 Privacy & security

- **All API keys now live in the operating system's secure credential store** —
  never in plain config files.
- **Per-user key isolation** — on a shared computer, another account can never
  see your API keys; switching back restores yours.
- **Account deletion built in** — Settings → Account → Delete account erases
  your server data and cancels any subscription. GDPR right-to-erasure,
  self-served.
- **Recording consent notice** — a one-time reminder before your first meeting
  recording that participants may need to consent under local law.
- **Terms of Service and Privacy Policy** — linked at sign-up and in the
  Account tab.

### 🖥️ Polish

- Redesigned Settings: clearer Pro labeling (purple PRO pills, LOCAL tags on
  on-device engines), glow highlighting on locked features, compact panels.
- API key fields: in-field show/hide eye, Copy, Test, and Save controls.
- Cloud model picker pruned to models verified working against the live APIs.
- macOS groundwork: capture modes that need Windows system-audio loopback are
  hidden on Mac, and a first-run guide walks through the three macOS
  permissions (Microphone, Accessibility, Input Monitoring).

### ⚙️ Under the hood

- Server-side entitlements: Pro checks, daily quotas, and rate limits are all
  verified on the server — with graceful local fallbacks when offline.
- 112 automated tests.
